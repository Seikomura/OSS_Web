# ผู้ดูแลระบบ

เข้าสู่เว็บด้วยบัญชี Admin แล้วเลือกเมนู **ผู้ดูแลระบบ**

- **เพิ่มผู้ดูแล**: ระบุชื่อ ชื่อผู้ใช้ และรหัสผ่าน 12–128 ตัวอักษร บัญชีใหม่มีสิทธิ์จัดการลูกค้า งาน และผู้ดูแลทั้งหมด
- **แก้ไข / รหัสผ่าน**: เปลี่ยนชื่อได้ หรือกรอกรหัสผ่านใหม่ เว้นช่องรหัสผ่านว่างเพื่อใช้เดิม ชื่อผู้ใช้เดิมเปลี่ยนไม่ได้
- **ปิดบัญชี / เปิดบัญชี**: ปิดการเข้าใช้และสิทธิ์จัดการ โดยเก็บข้อมูลไว้ สามารถเปิดใหม่ได้
- ปิดบัญชีที่กำลังใช้อยู่ไม่ได้ และระบบตรวจจากฐานข้อมูลไม่ให้ปิดผู้ดูแลคนสุดท้าย การเปลี่ยนสถานะพร้อมกันถูกจัดลำดับและตรวจสิทธิ์อีกครั้ง

ผู้ดูแลทุกคนมีสิทธิ์ระดับเดียวกัน ลูกค้าไม่เห็นรายชื่อผู้ดูแลและทำรายการจัดการผู้ดูแลไม่ได้

## กู้คืนเมื่อเข้าไม่ได้

ผู้ดูแลคนอื่นที่ยังเข้าได้สามารถตั้งรหัสผ่านใหม่ให้ได้ หากไม่มีใครเข้าได้ เจ้าของโปรเจกต์ Supabase ต้องกู้คืนบัญชีผ่านเครื่องมือฝั่งเซิร์ฟเวอร์ บัญชีปัจจุบันใช้ชื่อผู้ใช้และอีเมลภายในระบบ จึงยังไม่มีการส่งลิงก์รีเซ็ตผ่านอีเมล

รหัสผ่านเก็บใน Supabase Auth ไม่เก็บหรือแสดงรหัสผ่านเดิมในเว็บ คีย์สำหรับจัดการ Auth อยู่เฉพาะฝั่งเซิร์ฟเวอร์
