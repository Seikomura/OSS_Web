## วิธีทดลอง

1. เข้าบัญชี Admin แล้วเลือก “บัญชีลูกค้า” เพื่อเพิ่มลูกค้า แก้ไขรายละเอียด ดูรหัสผ่านล่าสุดด้วยปุ่มแสดง/ซ่อน ตั้งรหัสผ่านใหม่ ปิดบัญชี หรือลบลูกค้า
2. เลือก “งานทั้งหมด” เพื่อเพิ่มงานหรือแก้ไขบริษัท ชื่องาน ประเภทคำขอ และมาตรฐาน
3. เปิด “อัปเดตสถานะ” แล้วเลือกขั้นตอน ระบุสถานะ วันที่ และหมายเหตุ จากนั้นกดบันทึก
4. ใช้ปุ่มรูปตาในหน้าบัญชีลูกค้าเพื่อดูมุมมองของลูกค้ารายนั้น หรือออกจากระบบแล้วเข้าด้วยบัญชีลูกค้า
5. งาน มอ.5 แสดงขั้นตอน B2 เป็น “อยู่ระหว่างนำเข้า” ส่วน มอ.1 และ มอ.3 แสดง “ทำตัวอย่าง”
6. คืนค่าข้อมูลเริ่มต้นได้จากปุ่ม “คืนค่าข้อมูลตัวอย่าง” ในเมนู Admin บนจอคอมพิวเตอร์

เส้นทางมี 15 ขั้นตอน: เตรียมคำขอ 4 ขั้นตอน, โรงงาน 3 ขั้นตอน, Lab 4 ขั้นตอน และออกใบอนุญาต 4 ขั้นตอน สายโรงงานกับ Lab อัปเดตแยกกันได้ เปอร์เซ็นต์คิดจากจำนวนขั้นตอนที่เสร็จแล้ว สีเทาคือรอหรือยังไม่เริ่ม

## ขอบเขตของ Demo

- ข้อมูลและบัญชีถูกจำไว้ในเบราว์เซอร์เดียวกัน ไม่มีฐานข้อมูลร่วมระหว่างเครื่อง
- การ Login และการแยกมุมมองเป็นการจำลองเพื่อดูขั้นตอน ไม่ใช่การรักษาสิทธิ์บนเซิร์ฟเวอร์
- การเปิด Demo บนอีกเบราว์เซอร์หรืออีกเครื่องจะมีข้อมูลเริ่มต้นของตนเอง
- ใช้ข้อมูลและรหัสผ่านตัวอย่างเท่านั้น
- Demo เก็บรหัสผ่านล่าสุดของลูกค้าเป็นข้อความในเบราว์เซอร์เพื่อทดลองหน้าจอ Admin รหัสผ่านเก่าที่มีแต่ค่า hash จะไม่สามารถแสดงได้จนกว่าจะตั้งใหม่ ยกเว้นบัญชีที่ตรวจสอบแล้วว่ายังใช้ Demo1234
- ลิงก์ Sites เริ่มต้นเป็นส่วนตัวตามการตั้งค่าของแพลตฟอร์ม

## สำหรับย้ายไป Vercel + Supabase

ไฟล์ในชุด source เป็นเว็บ static ที่แยกหน้าตาและข้อมูลตัวอย่างแล้ว สามารถใช้เป็นต้นแบบของหน้าจอได้ แต่ยังไม่ได้ต่อ Supabase หรือ deploy ไป Vercel

ระบบจริงต้องแทนที่การ Login จำลองด้วย Supabase Auth, ผูกผู้ใช้กับบริษัทลูกค้า, เก็บบริษัท/งาน/ขั้นตอนในฐานข้อมูล, และตั้ง Row Level Security ให้ลูกค้าอ่านได้เฉพาะงานของบริษัทตนเอง การเพิ่มบัญชีและตั้งรหัสผ่านโดย Admin ต้องทำผ่านฝั่งเซิร์ฟเวอร์ที่ตรวจสิทธิ์ Admin แล้ว โดยไม่เปิดเผย service-role key ในเบราว์เซอร์

โครงสร้างข้อมูลที่แนะนำ: customer_companies, customer_members, jobs, job_steps และ admin_members รายการ job_steps เก็บ job_id, step_id, status, date, note และ updated_at รหัสผ่านจริงใช้ระบบ Supabase Auth ไม่เก็บไว้ในตารางบริษัท
